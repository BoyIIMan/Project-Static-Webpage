# Assets

Static files used across the site. Drop files here, then reference them with relative paths in HTML.

## Folders

| Folder | Use for | Example |
|--------|---------|---------|
| `images/` | Photos, avatars, project thumbnails, OG images | `assets/images/avatar.jpg` |
| `files/` | PDFs and downloads | `assets/files/resume.pdf` |

## Current files

| File | Used on |
|------|---------|
| `files/resume.pdf` | `resume.html`, `contact.html`, hero Resume button |

## Uploading new files

1. Add the file under `images/` or `files/`.
2. Reference it from the page you edit, e.g. `assets/images/my-screenshot.png`.
3. From blog posts, use `../../assets/images/...`.

See `EDITING.md` in the parent folder for full update workflows (blog, projects, resume).
